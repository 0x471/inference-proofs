    Every system on the ladder gets the same request, the same six checks and one figure. This page draws each step. The Checks page holds the rules word for word.

    The request

    Commit, prove, verify

    Six checks

    Each check runs the publisher's own prover, honestly, at its pinned commit. Three of them change one thing a verifier must refuse. These are refused changes with the publisher's own prover, not an attempt to forge a proof, so they cannot show that no forged proof exists. That rests on the soundness the publisher states, which the Integrity petal grades.

    The figure

    The ladder ranks the systems that passed on one model by one figure, cost vs serving: the GPU time of a proved reply over the GPU time of serving the same reply without a proof.
