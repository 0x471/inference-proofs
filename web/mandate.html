    What we do

    Pinned commitAGENTS.md, rule 1 (new tab)
    Each system runs at one pinned public commit, and our adapter passes no setting the system's documentation does not name. FlashProve runs its upstream commit unchanged. SASH runs a commit of a pull request to SASH that this project's owner wrote and upstream has not merged (see Ties).
    Same requestRFC-0018, Prompts, PR-2 (new tab)
    Every system gets the same request. Its prompts come from a public randomness beacon: drand's first round after the commit that froze the level, by that commit's own time, which our own clock sets. GitHub recorded each freeze 2 s after that time. The level was frozen three times on 2026-11-11, and each freeze drew new prompts; every counted run uses the third draw.
    Sample sizeAGENTS.md, rule 5 (new tab)
    Cost figures come with their sample size and each counted session's value, never one best run.
    ComputedRFC-0018, CO-6 (new tab), CH-6 (new tab)
    Check states and figures are computed from stored run records. No reviewer sets a state or types a figure.
    Reproduced firstRFC-0018, CH-8 (new tab)
    When a verifier accepts a changed model, prompt or reply in our adapter, the check reads not decided (not reproduced), and the publisher is told. The check reads failed only once a record shows the system's own command, run outside our adapter, accepting the same input.

    What we do not do

    Payment
    We take no payment for a listing, a position or a run.
    ProversAGENTS.md, What this project is (new tab)
    We run provers. We do not build our own or certify any.
    Not testedRFC-0018, Non-Goals (new tab)
    No check tries to forge a proof or recover the weights. The system's page quotes the publisher on soundness and weight secrecy.
    RankingRFC-0018, OR-1 (new tab)
    We rank only systems that passed the six checks, and never across models.

    How to check us

    LabelsAGENTS.md, rule 2 (new tab)
    Every figure carries its unit and its record, and a timed figure says what was timed. Nobody else has rerun any of our runs.
    RepositoryREADME.md, Licence (new tab)
    The rules, the adapters, the measuring code and the run records are in one public repository. Proofs, weights and other bulk files stay outside it, named by digest. The proofs are not public yet.
    RebuildREPRODUCE.md, Tier 1 (new tab)
    Anyone can rebuild the board from the run records, recompute every figure and validate the repository on a laptop, with no GPU. Verifying a proof again needs its bytes.
    Level 1levels/L1.yaml (new tab)
    Frozen 2026-11-11. The models, the request, the prompts' corpus and beacon, and the constants of the cost, fidelity and order rules are one file. It was frozen three times that day, before the first counted run, each time with a fresh beacon round, and has not changed since. A change of rule is meant to make a new level. But RFC-0018 has changed since the last freeze, and some rules added to it decided rows.

    Changes and corrections

    Contest a rowissues (new tab)
    Open an issue naming the row and the fact you hold wrong, with your source. The answer goes in the issue, and a change goes in the list below.
    A petalRFC-0018, GL-1 (new tab)
    A statement petal moves on a sentence the publisher wrote at the pinned commit, quoted with its link, or on a failed check. A state we read rather than copied says so and is graded Mostly met at most. Fidelity moves on a fidelity run.
    A checkRFC-0018, CH-6 (new tab)
    A check moves on a stored run record only. A changed input accepted in our adapter fails a check once the system's own command accepts it too.
